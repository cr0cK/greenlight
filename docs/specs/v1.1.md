# Greenlight v1.1 specification

## Goal

Show which version of Greenlight is installed, so a bug report can name it without opening the
Extensions app.

## Preferences

- An **About** group at the bottom of the preferences window shows a **Version** row with the
  `version-name` from `metadata.json`, such as `1.1.0`. The value is selectable, so it can be
  copied into an issue.
- The row is read-only and is not part of **Save preferences**.
