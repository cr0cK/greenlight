# Greenlight v1.2 specification

## Goal

Show pull request labels, so a row tells what kind of change it is without opening it.

Watch every repository of an owner except a few, without listing dozens of repositories to keep.

## Pull request rows

- The first line shows the labels right after the `#number` badge, before the title.
- Each label is a badge in its GitHub color. Its text is dark on light colors and white on dark
  ones; a label without a valid color uses the neutral number badge color.
- At most three labels show; the rest collapse into a `+N` badge whose accessible name lists them.
- Long label names ellipsize, so the title keeps its room.
- Labels come from `gh search prs --json labels`, in the same request as the rest of the row.

## Preview

- The preview shows up to six labels under the title, for pull requests as well as issues, in the
  same colors as the rows. They come from the existing preview GraphQL request.

## Quick open

- The quick open placeholder lists the accepted forms: `Open issue or PR: repo #42,
  owner/repo#42, #42 or URL`.

## Preferences

- An owner row has no **Remove** button: its switch pauses or resumes it. A paused owner does
  not expand, so its repositories cannot be chosen until it is turned back on.
- An expanded owner has a **Repositories** selector with three modes:
  - **All**: every repository, including new ones. No repository list.
  - **All except…**: new repositories are monitored; the loaded list turns off the ones to skip.
  - **Only…**: only the repositories turned on; new repositories are skipped.
- A repository switch on always means monitored. Changing between **All except…** and **Only…**
  keeps every switch; only the rule for new repositories changes. Leaving **All** turns every
  switch on.
- Without a loaded list, the new mode's selection is derived from the old one once the list
  loads, and **Save preferences** waits for it.
- The owner subtitle reads `All repositories`, `All except N repositories`, or
  `N selected repositories`.

## Owner filter settings

- Each owner in `owner-filters` gains `excludedRepositories`, used only when `repositories` is
  null. Settings without it read as no exclusions; a version without this feature ignores it and
  monitors every repository of that owner.

## Search scopes

- An owner with exclusions gets its own `gh search prs` command, with `-repo:owner/name` terms
  after `--`, within the existing query length and qualifier bounds.
- Exclusions that do not fit are filtered from the results on the client only. Because that can
  shorten a full page, the search runs again with a larger limit, up to 1000, until the owner
  yields its share of the 30 most recent pull requests; group and panel counts follow the
  filtered list.
